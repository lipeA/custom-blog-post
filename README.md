# custom-blog-post

pluguin para wordpress. gerenciamento de post

✔ custom post type “Blog Post”
✔ campos personalizados (imagem destaque obrigatória, etc.)
✔ ordenação automática por data
✔ página de listagem em grid
✔ template single
✔ shortcode para exibir os 5 últimos posts na home
✔ estilo moderno minimalista

Você precisa criar uma pasta no WordPress:
/wp-content/plugins/custom-blog-post/

e dentro dela coloque o arquivo:
custom-blog-post.php

# COMO USAR:

🔹 Página do Blog (listagem em grid):

Crie uma página chamada Blog
Coloque dentro dela coloque esse shot-code:
[blog_grid]

# TEMPLATE DO POST INDIVIDUAL

coloque o arquivo para ver os posts individuais:
/wp-content/themes/SEU-TEMA/single-cbp_post.php
